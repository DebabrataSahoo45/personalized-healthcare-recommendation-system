# Personalized Healthcare Recommendation System

## Project Overview
This project is a Machine Learning based Personalized Healthcare Recommendation System that predicts patient health risk levels and provides personalized diet and exercise recommendations.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit
- Plotly
- Joblib

## Features
- Health Risk Prediction
- Diet Recommendation
- Exercise Recommendation
- Random Forest Classification
- Interactive Dashboard
- Healthcare Data Analysis

## Dataset
The dataset contains 2000 patient records with demographic, clinical, genetic, and lifestyle-related features.

## Model Performance
- Algorithm: Random Forest Classifier
- Accuracy: 99.75%
- Test Samples: 400
- Misclassified Samples: 1
